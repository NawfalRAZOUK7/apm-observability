# Traceability

This public repository contains the sanitized source code and public documentation.

Internal evidence, raw reports, archived experiments, operational notes, and non-public artifacts are maintained in a separate private repository:

- Repository: `apm-observability-internal`
- Access: restricted to project maintainers

Private evidence mapping:
- `reports/`: raw test evidence and execution reports
- `archive/`: legacy experiments, internal runbooks, and sensitive historical artifacts
- deployment-specific and machine-specific operational material: private repo only

No active secrets, private keys, or environment-specific confidential artifacts are intended to be stored in this public repository.
